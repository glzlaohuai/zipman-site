支持

常见问题的答案都在这里。

ZipMan 需要什么系统？

macOS 26 或更高版本，原生支持 Apple 芯片和 Intel 芯片的 Mac。

怎么安装？

打开下载的 DMG，把 ZipMan 拖到“应用程序”文件夹。如果直接从 DMG 或“下载”文件夹打开，ZipMan 会提示你把它移到“应用程序”文件夹。

怎样让双击压缩包时用 ZipMan 打开？

首次启动的欢迎页里可以直接设置；之后也可以在 ZipMan 的“设置 › Finder”中点“设为默认”。双击时是直接解压还是打开浏览窗口，在“设置 › 通用”中选择。

右键菜单里找不到 ZipMan 的命令？

在 ZipMan 的“设置 › Finder”中点“扩展设置…”，在打开的系统设置里启用 ZipMan 的 Finder 扩展。未启用时，这些命令在右键菜单的“快速操作”或“服务”子菜单中。

按空格看不到压缩包里的文件？

在“系统设置 › 通用 › 登录项与扩展 › 快速查看”中确认 ZipMan 已打开。文件名经过加密的压缩包无法预览，请在 ZipMan 中输入密码后浏览。

分卷压缩包怎么解压？

把所有分卷放在同一个文件夹里，打开其中任意一卷即可，ZipMan 会自动从第一卷开始解压。支持 .part1.rar、.r00、.7z.001、.zip.001、.z01 等命名方式。

为什么别人打不开我加密的 zip？

系统的“归档实用工具”和 Windows 资源管理器都打不开 AES-256 加密的 zip，需要用 ZipMan、7-Zip 等工具。需要兼容时，压缩时把“加密方式”选为 ZipCrypto（安全性较低）。分卷 zip（.zip.001…）同样需要 ZipMan、7-Zip 或 Keka 才能打开。

解压出来的中文文件名是乱码？

ZipMan 会自动识别 Windows 上常见的 GBK 编码文件名。如果仍然出现乱码，请向我们反馈，方便的话附上压缩包的来源或文件列表。

怎么更新？

ZipMan 会自动检查更新，也可以在菜单“ZipMan › 检查更新…”中手动检查。更新选项在“设置 › 关于”中。

怎么卸载？

退出 ZipMan，把它从“应用程序”文件夹移到废纸篓。如果曾把它设为默认解压工具，可以在 Finder 中对压缩包“显示简介 › 打开方式”改回其他应用。

还有问题？

ZipMan 发布后，可以在 GitHub 上提交问题和建议。
