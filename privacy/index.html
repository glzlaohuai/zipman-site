隐私政策

更新于 2026 年 11 月 20 日

ZipMan 不收集、不上传你的任何个人信息或文件。

你的文件

压缩、解压、浏览和编辑都在你的 Mac 上完成，文件不会离开你的电脑。

在压缩包里编辑文件时，ZipMan 会把它临时解压到本机的临时文件夹，用完即删除。

密码

你输入的密码只用于当次压缩或解压，不会被保存，也不会被发送到任何地方。

网络

ZipMan 唯一的联网操作是检查更新：它会定期从 GitHub 读取更新信息，有新版本时提示你安装（开启“自动下载并安装更新”时则自动完成），安装包同样从 GitHub 下载。

这些请求只包含常规的网络信息（例如 IP 地址）和 ZipMan 的版本号，由 GitHub 按其隐私政策处理。你可以在 ZipMan 的“设置 › 关于”中关闭“自动检查更新”。

Finder 扩展与快速查看

Finder 扩展和快速查看扩展运行在系统沙盒中，只读取你右键或预览的文件，并通过本机的共享文件夹把命令交给 ZipMan。

没有账号、广告和统计

ZipMan 不需要注册账号，不含广告，也不使用任何第三方统计或崩溃收集服务。

本网站

本网站由 GitHub Pages 托管，不使用 Cookie，也不加载任何统计脚本。GitHub 可能出于安全目的记录访问日志（例如 IP 地址）。
